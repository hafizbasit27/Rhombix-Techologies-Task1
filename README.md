# Rhombix-Techologies-Task1
# 📊 E-Commerce Customer Segmentation (RFM Analysis)
This repository contains a full-scale Data Analytics project focused on segmenting over 4,300 unique customers using the **RFM (Recency, Frequency, Monetary)** framework to drive targeted marketing and business growth strategies.

## 🚀 Project Overview
In this project, I transformed raw transactional data into actionable business intelligence through a structured 6-phase pipeline:
1. **Data Understanding:** Initial inspection of the E-commerce dataset.
2. **Data Cleaning:** Handling missing values and ensuring data integrity.
3. **Exploratory Data Analysis (EDA):** Visualizing sales trends and customer behavior patterns.
4. **RFM Modeling:** Engineering behavioral scores and segmenting the audience.
5. **Data Visualization:** Creating executive dashboards using Matplotlib.
6. **Strategic Insights:** Developing tailored recommendations for business stakeholders.

## 📁 Repository Structure
* **Notebooks/:** Contains step-by-step Jupyter notebooks for each project phase.
* **Data/:** *(Referenced via Cloud Storage due to file size constraints)* Contains raw transactional records and multi-phase checkpoint outputs.
